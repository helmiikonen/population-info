# Kuntien väestötiedot

Sovelluksessa voi tarkastella yksittäisten kuntien ja koko maan väestömuutoksia aikavälillä 2003-2025. 
Väestötiedot haetaan Tilastokeskuksen StatFin-tietokannasta.

### Kuinka voit testata sovellusta?

* Avaa komentorivi ja siirry haluamaasi hakemistoon
* Kloonaa repositorio komennolla `git clone git@github.com:helmiikonen/population-info.git`
* Siirry projektin frontend-hakemistoon komennolla `cd municipality-frontend`
* Asenna tarvittavat riippuvuudet komennolla `npm install`
* Komento `npm start` käynnistää sekä sovelluksen frontendin että backendin
* Sovellus käynnistyy selaimessa oletuksena osoitteeseen `http://localhost:5173`
